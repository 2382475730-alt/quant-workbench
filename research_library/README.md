# 研究资料库

`baseline_20261024/` 保存整理前工作区的完整研究材料，内部相对路径保持不变。

| 基线内路径 | 内容 |
|---|---|
| `quant_workbench/src/quant_workbench/` | 当前四条主线仍在复用的冻结计算与历史界面代码 |
| `quant_workbench/data/` | 共享行情、标准化面板、原始响应和来源文档 |
| `quant_workbench/artifacts/` | 原实验、账本、冻结清单和历史检查证据 |
| `quant_workbench/reports/` | 完整研究报告、图表、可复核笔记 |
| `quant_workbench/research/` | 各研究协议、方法、边界和来源说明 |
| `quant_workbench/report_app/` | 历史网页报告工程，当前窗口不启动它 |
| `src/`、`data/`、`artifacts/` 等父层目录 | 更早的板块工作台代码与快照，保留备查 |

资料库中存在当前运行依赖，不能整体删除。历史文件中的“当前”“最新”描述只对应原交付时间；今天的启动与管理以工作区根README为准。

所有来源、失败实验和旧版本仍保留。后续如果要压缩缓存或抽取公共引擎，应单独做映射及账本一致性检查；不要直接重排冻结包内部路径。
